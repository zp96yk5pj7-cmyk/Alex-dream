# Alex-dream 日记本

> 私人在线日记本，基于 GitHub 仓库的 Markdown 日记系统，保留完整版本历史。

## 日记本说明

这是一个私人在线日记本，所有日记以 Markdown 格式保存在本仓库中。
每次修改都会通过 Git 记录，形成完整的版本历史，方便回顾与回溯。

## 目录结构

- `2026/` 按「年/月」分层的日记目录，如 `2026/08/`
- `templates/` 日记写作模板
- `ideas/` 灵感与想法记录

## 使用方式

1. 在对应年月目录下新建以日期命名的文件，如 `2026/08/2026-08-21.md`
2. 参照 `templates/日记模板.md` 的字段填写
3. 随时将灵感写入 `ideas/` 目录
